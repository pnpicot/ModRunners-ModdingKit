# ILobby.DisabledSlotOptions property

The options of an empty slot that are turned off, on every slot: greyed out, skipped by the selection, and doing nothing when pressed. None by default. The game turns some off too: before anyone joins, only Add Local of the first slot is available.

```csharp
public SlotOptions DisabledSlotOptions { get; set; }
```

## Remarks

Turning AddLocal off leaves no way to join a custom match that nobody joined yet.
