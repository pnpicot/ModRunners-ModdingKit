# ILobby.ReadyChanged event

Raised on the game's thread when a slot gets ready in the character selection, or cancels. It is raised as the change happens, before the slot holds it, so read the new value from the event.

```csharp
public event EventHandler<SlotReadyChangedEventArgs>? ReadyChanged;
```

## Remarks

Offline, the last slot getting ready ends the character selection at once: [`ScreenChanged`](../../ModRunners.Api/IGame/ScreenChanged.md) to the map selection follows immediately, and the game clears every slot's readiness there, without raising this event.
