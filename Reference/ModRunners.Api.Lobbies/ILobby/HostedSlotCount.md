# ILobby.HostedSlotCount property

How many slots the custom matches and practice matches against bots that this game hosts have, from 4, the game's, to 128. A change applies from the next of those lobbies.

```csharp
public int HostedSlotCount { get; set; }
```

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentOutOfRangeException | The count is below 4 or above 128. |

## Remarks

A game joining a modded lobby takes its host's count, and every other lobby has four. The character selection shows the first four slots.
