# ILobby.TeamsShareBoost property

Whether a team's members share one boost meter and one count of Boosta Cokes, as the game's pairs do: the meter holds every member's own maximum added, and the count 10 Boosta Cokes per member, each worth 1 / n of its effect for a team of n. True by default. Set to false, every runner has its own meter and count, at full value.

```csharp
public bool TeamsShareBoost { get; set; }
```

## Remarks

It applies offline and in modded lobbies, as numbered teams do ([`MaxTeamSize`](./MaxTeamSize.md)), and lasts until a mod changes it. Every game of a modded lobby sets the same, as from a lobby option.
