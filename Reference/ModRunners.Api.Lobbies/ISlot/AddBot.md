# ISlot.AddBot method

Puts a bot in the slot, as its Add Bot option does: a random character no other slot has, or one another slot has when none is left. The bot is played from this game, and gets ready when this game's players do.

```csharp
public void AddBot(BotDifficulty difficulty)
```

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentOutOfRangeException | *difficulty* is not one of the four. |
| InvalidOperationException | The slot is not empty, this game is not on the character selection of a custom match or a practice match it hosts, or none of this game's players joined the lobby yet. |
