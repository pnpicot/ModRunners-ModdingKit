# ITeam.Color property

The team's color. With numbered teams, the game's red for team 1, its green for team 2, and a color of its own for each next team. For the game's pairs, red for the pair holding the first slot, and green for any other, as the game shows them.

```csharp
public Color Color { get; set; }
```

## Remarks

While [`MaxTeamSize`](../ILobby/MaxTeamSize.md) is set, the lobby shows it on its slots' team background, and a match on the player indicator over the members of a team with a player on this computer, and on the team's HUD cards. A color set lasts until the lobby closes. Its alpha is ignored.
