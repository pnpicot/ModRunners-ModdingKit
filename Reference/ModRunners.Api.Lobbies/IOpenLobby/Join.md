# IOpenLobby.Join method

Leaves what the player is doing and joins the lobby, as accepting an invitation does, at the end of the frame. A Solo run or an offline match in progress is lost, as when quitting it. The host can still refuse, for lack of room: the player then lands in the game's own search.
