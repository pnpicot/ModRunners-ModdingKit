# SlotOptions enumeration

The options of an empty slot in the character selection of a custom match or a local party, which only the lobby's host sees.

| name | value | description |
| --- | --- | --- |
| None | `0x0` |  |
| AddOnline | `0x1` | Opens the slot to a player searching for a quick match. |
