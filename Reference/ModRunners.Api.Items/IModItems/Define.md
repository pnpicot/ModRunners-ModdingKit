# IModItems.Define method

Adds an item to the game. Only during [`OnLoad`](../../ModRunners.Api/IMod/OnLoad.md).

```csharp
public IModItem Define(string id, string name, IImage icon, int maxUses = 1)
```

| parameter | description |
| --- | --- |
| id | The item's id within the mod, which never changes between versions of the mod. |
| name | What players call it. |
| icon | Its icon, in the HUD and above its runner, from [`LoadImage`](../../ModRunners.Api.Drawing/IDrawing/LoadImage.md): drawn in a 64-pixel square, so a square image looks best. |
| maxUses | How many uses it gives, from 1 to 9, as the triple box gives 3. |

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentException | *id* or *name* is empty, *id* is already defined by the mod, or *icon* is not from [`IDrawing`](../../ModRunners.Api.Drawing/IDrawing.md). |
| ArgumentOutOfRangeException | *maxUses* is not from 1 to 9. |
| InvalidOperationException | The mod's [`OnLoad`](../../ModRunners.Api/IMod/OnLoad.md) is over, or the mods' items already use every byte the game leaves free. |
