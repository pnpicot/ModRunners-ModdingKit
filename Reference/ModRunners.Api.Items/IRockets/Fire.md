# IRockets.Fire method

Fires a rocket for the runner of a slot, as a use does, its sound included, without using an item: it follows that runner's values, and homes in like the use's rocket.

```csharp
public IRocket Fire(ISlot owner, Point position, float angle)
```

| parameter | description |
| --- | --- |
| owner | The slot whose runner fires it. |
| position | Where it starts, in level units. |
| angle | The direction it starts in, in degrees: 0 points right and the angle grows clockwise, so -90 points up. |

## Return Value

The rocket fired.

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | The slot has no runner, as outside a match. |

## Remarks

The rocket only exists on the games that fire it. Fired from [`Fired`](./Fired.md), which every game raises for each use, it exists on every game that has the mod.
