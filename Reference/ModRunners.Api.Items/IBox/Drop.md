# IBox.Drop method

Drops a box for the runner of a slot, as a use does, its sound included, without using an item: it falls until it lands, with that runner's values, and stands until something breaks it.

```csharp
public IDroppedBox Drop(ISlot owner, Point position)
```

| parameter | description |
| --- | --- |
| owner | The slot whose runner drops it. |
| position | The top-left corner of its hitbox, in level units. A use drops it just behind its runner. |

## Return Value

The box dropped.

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | The slot has no runner, as outside a match. |

## Remarks

The box only exists on the games that drop it. Dropped on every game, for example when [`Happened`](../IItems/Happened.md) tells of a use or from a mod message, it exists on every game that has the mod. It is no use: [`Happened`](../IItems/Happened.md) tells of none.
