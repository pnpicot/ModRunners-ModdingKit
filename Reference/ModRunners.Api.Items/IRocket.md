# IRocket interface

A rocket, from when it is fired until it explodes. A runner's rockets are reused, so read it from [`InPlay`](./IRockets/InPlay.md) or [`Fired`](./IRockets/Fired.md) when needed: once it exploded, one kept from before is out of date, and may be another flight of the same rocket.

## Remarks

Every game simulates every runner's rockets and their explosions, so a change to a rocket only agrees across a match when every game makes it.

The values set on a rocket apply to its flight only: its next flight starts from its runner's values again ([`Items`](../ModRunners.Api.Runners/IRunner/Items.md)).
