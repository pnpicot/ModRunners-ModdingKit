# IModItems interface

The items this mod adds to the game. Runners take them from item pickups, hold them with their icon, and use them with the item button, as the game's own items.

## Remarks

The game knows its items by a byte, which every game of a match shares. The Runtime gives each mod item the bytes the game does not use, once every mod has loaded, in the order of the mods' ids and the items' ids, so every game with the same mods gives an item the same bytes.

A game without the mod shows a mod item as the confetti's icon, and plays nothing when it is used.
