# IItemPickups.GetWeightFactor method

How much more likely an item is to be rolled than in the game, for the runners this game plays: 1 by default. It multiplies the weight the game gives the item for each roll, rounded. 0 never rolls it. When every weight is 0, the roll gives the golden hook.
