# IItems.Hitting event

Raised on the game's thread just before an item hits a runner, on each game that decides the hit ([`IsDecidedHere`](../ItemHittingEventArgs/IsDecidedHere.md)). A handler can refuse it.

```csharp
public event EventHandler<ItemHittingEventArgs>? Hitting;
```

## Remarks

It is raised only for a hit the game would make, so never for a drilling runner. A fireball, an ice beam or a box touching a runner over several frames asks once per throw, beam or drop, and keeps the answer. A refused hit raises no Hit.

Every game decides the hits on its own copy of a runner, so a mod refuses a hit on every game. A golden hook's lock cannot be refused.
