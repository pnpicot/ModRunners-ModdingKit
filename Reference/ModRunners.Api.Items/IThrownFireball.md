# IThrownFireball interface

A fireball, from when its runner throws it until it explodes. A runner's fireballs are reused, so read it from [`InPlay`](./IFireball/InPlay.md) when needed: once it exploded, one kept from before is out of date, and may be another throw of the same fireball.

## Remarks

Every game simulates every runner's fireballs and stuns the runners its own copy touches, so a change to a fireball only agrees across a match when every game makes it.
