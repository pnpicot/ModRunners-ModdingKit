# IConfettiRules.Throw property

How hard it throws its runner, as a multiple of the game's: 1 by default, 262.5 units per second back and 400 up. A runner already stunned is thrown back at 350, and down when its stun has more than 1.75 seconds left. Below 0, it throws the runner the other way.
