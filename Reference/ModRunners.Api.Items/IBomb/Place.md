# IBomb.Place method

Places the bomb of the runner of a slot, as a use does, its sound included, without using an item: it falls until it lands, with that runner's values, and stays until something sets it off ([`Explode`](../IPlacedBomb/Explode.md)). A runner has one bomb, so a bomb already placed moves there.

```csharp
public IPlacedBomb Place(ISlot owner, Point position)
```

| parameter | description |
| --- | --- |
| owner | The slot whose runner places it. |
| position | Its top-left corner, in level units. A use drops it just behind its runner. |

## Return Value

The bomb placed.

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | The slot has no runner, as outside a match. |

## Remarks

The runner's item does not become the detonator. A runner that holds the detonator sets this bomb off with it.

The bomb only exists on the games that place it. Placed on every game, for example when [`Happened`](../IItems/Happened.md) tells of a use or from a mod message, it exists on every game that has the mod. It is no use: [`Happened`](../IItems/Happened.md) tells of none.
