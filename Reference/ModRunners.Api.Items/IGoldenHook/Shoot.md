# IGoldenHook.Shoot method

Shoots the golden hook of the runner of a slot, as a use does, its sound included, without using an item: tied to its runner by the rope, it flies at that runner's speed, turning toward its target when it has one, and pulls the runner it locks onto.

```csharp
public IGoldenHookShot Shoot(ISlot owner, Point position, float angle, ISlot? target)
```

| parameter | description |
| --- | --- |
| owner | The slot whose runner shoots it. |
| position | The top-left corner of the hook, in level units. A use shoots it from where its runner's grapple starts. |
| angle | The direction it starts in, in degrees: 0 points right and the angle grows clockwise, so -90 points up. A use aims it at its target. |
| target | The slot whose runner it turns toward, or null to fly straight. A use aims at the runner most in front, never a teammate. |

## Return Value

The hook shot.

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentException | *target* is *owner*. |
| InvalidOperationException | The slot or the target's slot has no runner, as outside a match, or the runner's grapple or golden hook is out: the golden hook takes the grapple's rope. |

## Remarks

The hook only exists on the games that shoot it, and each game locks it on its own copy of a runner. Shot on every game, for example when [`Happened`](../IItems/Happened.md) tells of a use or from a mod message, it pulls on every game that has the mod. It is no use: [`Happened`](../IItems/Happened.md) tells of none.
