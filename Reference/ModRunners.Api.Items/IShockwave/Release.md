# IShockwave.Release method

Releases the shockwave of the runner of a slot, as a use does, its sound included, without using an item: the wave travels from the runner's middle to the target, then blasts there, with that runner's values. A runner has one shockwave, so one already out ends.

```csharp
public IReleasedShockwave Release(ISlot owner, Point target)
```

| parameter | description |
| --- | --- |
| owner | The slot whose runner releases it. |
| target | Where the wave blasts, in level units. A use's blasts up to 300 units ahead of its runner, the further the longer it was charged. |

## Return Value

The shockwave released.

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | The slot has no runner, as outside a match. |

## Remarks

The shockwave only exists on the games that release it. Released from [`Released`](./Released.md), which every game raises for each use, it exists on every game that has the mod. It is no use: [`Happened`](../IItems/Happened.md) tells of none.
