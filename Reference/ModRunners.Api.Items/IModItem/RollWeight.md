# IModItem.RollWeight property

How likely an item pickup is to give it, on the scale of the game's own weights: 0 by default, never. The game weighs each of its items by the runner's place, from 1 to 40: 15 is the shockwave's weight for a runner in the middle of the race. It joins the game's roll for the runners this game plays, as long as no game modifier decides the item.
