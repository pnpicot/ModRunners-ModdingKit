# IModItem.Used event

Raised on the game's thread when a runner uses the item, on every game, the runner's own first: each game plays the use for its copy of the runner, as for the game's items. The use was already taken from the runner's uses.

```csharp
public event EventHandler<ModItemUsedEventArgs>? Used;
```

## Remarks

The game's message of a use carries nothing but the item, so a use reads what every game already knows of the runner, such as where it is and which way it faces, or sends a message of its own.
