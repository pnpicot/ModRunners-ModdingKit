# IGoldenHookShot interface

A golden hook its runner shot, from the shot until it is released. A runner's golden hook is reused, so read it from [`InPlay`](./IGoldenHook/InPlay.md) when needed: once released, one kept from before is out of date, and may be another shot of the same hook.

## Remarks

Every game flies every runner's golden hook, and each releases its own copy when it leaves that game's view. The pulled runner's game has the last word on a lock.
