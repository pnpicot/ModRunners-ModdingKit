# IItemPickups interface

The item pickups of the map, and the items they roll from. Touching a pickup without an item gives the runner a random item, weighted by its place in the race, and the pickup comes back a few seconds later.

## Remarks

Only a runner's own game rolls its item, and tells the other games which one it got. A change to the roll therefore applies to the runners of the games that make it, so a mod makes it on every game.
