# IPlacedBomb interface

A bomb placed in the level, from when its runner drops it until it explodes. Read it from [`InPlay`](./IBomb/InPlay.md) when needed: once it exploded, one kept from before is out of date, and changing it does nothing.

## Remarks

Every game simulates every runner's bomb and pushes the runners its own copy's explosion reaches, so a change to a bomb only agrees across a match when every game makes it.
