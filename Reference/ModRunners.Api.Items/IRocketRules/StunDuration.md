# IRocketRules.StunDuration property

How long a runner a rocket's explosion reaches stays stunned: 1 second by default. A runner takes only one explosion per frame, so rockets exploding together stun it once. As for every stun in the game, a runner already stunned is not stunned again above 1.75 seconds left, and otherwise keeps at least 0.5 seconds.
