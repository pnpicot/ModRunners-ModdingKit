# IDroppedBox interface

A box its runner dropped, from the drop until it breaks. A runner's boxes are reused, so read it from [`InPlay`](./IBox/InPlay.md) when needed: once broken, one kept from before is out of date, and may be another drop of the same box.

## Remarks

Every game simulates every runner's boxes and breaks its own copy of one, so a change to a box only agrees across a match when every game makes it. A runner touching a box breaks it on every game.
