# IFireball.Throw method

Throws a fireball for the runner of a slot, as a use does, its sound included, without using an item: it flies, falls and rolls as the use's, with that runner's values.

```csharp
public IThrownFireball Throw(ISlot owner, Point position, float angle)
```

| parameter | description |
| --- | --- |
| owner | The slot whose runner throws it. |
| position | The middle of the ball's top edge, in level units. A use throws it 65 units ahead of its runner's middle. |
| angle | The direction it is thrown in, in degrees: 0 points right and the angle grows clockwise, so -90 points up. A use throws it at -17 facing right or -163 facing left, and at -45 or -135 when aiming up on the ground. |

## Return Value

The fireball thrown.

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | The slot has no runner, as outside a match. |

## Remarks

The fireball only exists on the games that throw it. Thrown on every game, for example when [`Happened`](../IItems/Happened.md) tells of a use or from a mod message, it exists on every game that has the mod. It is no use: [`Happened`](../IItems/Happened.md) tells of none.
