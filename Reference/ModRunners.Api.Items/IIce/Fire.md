# IIce.Fire method

Fires the ice for the runner of a slot, as a use does, its sound included, without using an item: the beam charges, then fires from the runner's top edge to one side, moving with the runner, for that runner's values' times. A runner has one beam, so firing it again while it charges or fires starts it over.

```csharp
public IIceBeam Fire(ISlot owner, bool towardRight)
```

| parameter | description |
| --- | --- |
| owner | The slot whose runner fires it. |
| towardRight | Whether the beam goes to the runner's right, or to its left. A use fires it toward the direction held, or the way the runner faces. |

## Return Value

The beam fired.

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | The slot has no runner, as outside a match. |

## Remarks

The beam only exists on the games that fire it. Fired on every game, for example when [`Happened`](../IItems/Happened.md) tells of a use or from a mod message, it exists on every game that has the mod. It is no use: [`Happened`](../IItems/Happened.md) tells of none.
