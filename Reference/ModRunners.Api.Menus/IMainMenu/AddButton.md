# IMainMenu.AddButton method

Adds a button under one of the game's, in the style of that button's group. The buttons above it move up to make room, so the bottom button stays in place. Buttons added under the same game button are placed in the order they were added.

```csharp
public IMenuButton AddButton(string text, MainMenuButton below)
```

| parameter | description |
| --- | --- |
| text | The button's text. The game writes it in capitals, and shrinks a text too wide to fit. |
| below | The game's button to place it under. |

## Return Value

The button added.

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentNullException | *text* is null. |
| ArgumentOutOfRangeException | *below* is not one of the game's buttons. |
