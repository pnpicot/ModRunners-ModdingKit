# IMenuPage&lt;TButton&gt;.AddButton method (1 of 2)

Adds a button of its own to the page, outside the column: the game's confirm button from its popups, with the text on it. The arrows reach it from the column's top button, and it lights while selected. Buttons placed this way come before the column, in the order they were added.

```csharp
public IMenuButton AddButton(string text, string description, Point position)
```

| parameter | description |
| --- | --- |
| text | The button's text. The game writes it in capitals, and shrinks a text too wide to fit. |
| description | What the page says about the button while it is selected. Empty for none. |
| position | The button's middle, in the page's units: 1280 wide and 720 high from its top left corner, whatever the screen's size. |

## Return Value

The button added.

# IMenuPage&lt;TButton&gt;.AddButton method (2 of 2)

Adds a button under one of the game's, in the style of that button. The buttons above it move up to make room, so the bottom button stays in place, and the rows draw closer together once the column would reach the top of the screen. Buttons added under the same game button are placed in the order they were added. The player reaches them with the arrows and the mouse like the game's own.

```csharp
public IMenuButton AddButton(string text, string description, TButton below)
```

| parameter | description |
| --- | --- |
| text | The button's text. The game writes it in capitals, and shrinks a text too wide to fit. |
| description | What the page says about the button while it is selected, where it shows its own entries' descriptions. Empty for none. |
| below | The game's button to place it under. |

## Return Value

The button added.

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentNullException | *text* or *description* is null. |
| ArgumentOutOfRangeException | *below* is not one of the game's buttons. |
