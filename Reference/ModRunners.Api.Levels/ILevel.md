# ILevel interface

The map being played, from when it is built at the start of a match to the end of the match. Every round of the match plays on it.

## Remarks

Its tiles are a grid counted from the map's top left tile, at (0, 0). The tile (x, y) covers the square of side [`TileSize`](./ILevel/TileSize.md) whose top left corner is at (x × [`TileSize`](./ILevel/TileSize.md), y × [`TileSize`](./ILevel/TileSize.md)), in level units.
