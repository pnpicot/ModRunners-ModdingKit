# ILevel.SetModTileType method

Gives the tile at a place of the map a mod's tile type, which it is drawn with from the next frame, or takes it away with null. The tile keeps its [`TileType`](../../ModRunners.Api.Tiles/TileType.md): its form, its collision and what it does to runners and hooks.

```csharp
public void SetModTileType(int x, int y, IModTileType? type)
```

| parameter | description |
| --- | --- |
| x | The column, from 0 on the left. |
| y | The row, from 0 at the top. |
| type | A type from [`Define`](../../ModRunners.Api.Tiles/IModTileTypes/Define.md), of any mod, or null. |

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentOutOfRangeException | The place is outside the map. |
| ArgumentException | The tile is empty, which is never drawn, or *type* is not from [`Define`](../../ModRunners.Api.Tiles/IModTileTypes/Define.md). |
| InvalidOperationException | The level is closed. |

## Remarks

The tile keeps it until the level is closed, or until the tile is emptied, as the destructible environment modifier empties tiles. It is this game's only: nothing is sent.
