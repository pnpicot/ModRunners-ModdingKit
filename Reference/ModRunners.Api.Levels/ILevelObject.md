# ILevelObject interface

An object a mapper placed on the map in the level editor, besides its tiles: a deco, a text, a gate, a lever, a trigger zone, a checkpoint, spikes and the rest, as the map's file holds it. It is the same on every game, whatever the player's Quality option, which only leaves some decos undrawn.

## Remarks

Its properties are the level editor's, as the mapper set them. The keys of the two kinds mappers use to show things:

* a text (`"TextDeco"`): `"Text"`, what the mapper typed;
* a deco (`"Deco"`): its image, `"Bundle"` (a stage, such as `"StageAirport"`) and `"Image ID"` (its number among that stage's images), then `"Layer"`, `"Flipped"` (`"TRUE"` or `"FALSE"`), `"Rotation"`, `"Color R"`, `"Color G"` and `"Color B"` (0 to 255), `"TriggerId"`, the trigger group it answers, and the keys of its animation.
