# ISoundEffects interface

How a sound sounds: its volume, its pitch, its filters and its effects. Every value's default leaves the game's sound as it is.

## Remarks

A change applies to the sound's next plays, and to the plays still heard, except for the reverb, which a play keeps from its start.

For a runner's own values, setting a value throws InvalidOperationException when the runner no longer exists.
