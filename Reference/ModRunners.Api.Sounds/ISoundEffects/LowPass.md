# ISoundEffects.LowPass property

The cutoff frequency of a low-pass filter, in hertz from 20 to 20,000, or null for none, the default. The frequencies above it fade, so a lower cutoff makes the sound softer and more muffled, as if heard through a wall.

public float? LowPass { get; set; }

## Remarks

The filter only reaches a sixth of the sound device's sample rate, 8,000 hertz at 48,000 hertz. A higher cutoff lets every frequency through.
