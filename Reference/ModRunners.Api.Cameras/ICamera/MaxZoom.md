# ICamera.MaxZoom property

The widest zoom the game's framing reaches on its own: in a match as the runners spread, in a Solo run as the runner's speed rises past the high speed. 1.35 by default.

```csharp
public float MaxZoom { get; set; }
```

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentOutOfRangeException | The value set is below 1 or infinite. |

## Remarks

A wider view shows more tiles, which the game keeps in video memory until the level changes: about 280 MB at a zoom of 4 on the largest maps, where scrolling can also stutter.
