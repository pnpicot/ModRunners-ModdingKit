# ICamera.Placing event

Raised on the game's thread at each frame of a match or a Solo run, once the game's framing has placed the camera, and before the shake and the level's edges move it. A handler can move the camera and zoom it for this frame.

```csharp
public event EventHandler<CameraPlacingEventArgs>? Placing;
```

## Remarks

It is raised while the game is paused and while a replay is watched too. The match's eliminations use the camera as the handlers leave it.
