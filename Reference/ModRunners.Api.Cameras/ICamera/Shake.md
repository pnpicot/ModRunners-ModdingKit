# ICamera.Shake method

Shakes the camera, as the game does for an explosion or an elimination. A new shake replaces the one running, even a stronger one. Nothing happens when no level is shown.

```csharp
public void Shake(TimeSpan duration, float intensity, bool fadesOut)
```

| parameter | description |
| --- | --- |
| duration | In game time, which the game's speed changes. |
| intensity | How far the view moves: an elimination shakes it at 2.5, a rocket at 2. The view moves by a new random amount at each frame, further at higher screen resolutions. |
| fadesOut | Whether the intensity falls steadily to 0 by the end, instead of staying the same. |

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentOutOfRangeException | *duration* is not above 0, or *intensity* is below 0 or infinite. |
