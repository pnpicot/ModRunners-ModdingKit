# IListOption.SortedBy&lt;T&gt; method

Keeps the items in the order of *field*'s values, and no two items with the same value: the options page skips the values other items hold, and shows the items in their new order once the player leaves the list. The player cannot reorder them.

```csharp
public void SortedBy<T>(IListField<T> field)
```

| parameter | description |
| --- | --- |
| field | A number, choice, key or text field of the list. |
