# IListOption interface

An option that is a list: the player adds, removes and reorders its items, up to [`MaxItems`](./IListOption/MaxItems.md), and each item has the fields the mod declares on the list. Its fields and its default items are declared in [`OnLoad`](../ModRunners.Api/IMod/OnLoad.md), before its items are read.

## Remarks

The items are saved between starts under the list's id, each value under its field's id, so a field added in a later version of the mod takes its default in the saved items, and a field's label can change. A list declared through [`Lobby`](./IOptions/Lobby.md) takes a modded lobby host's items, as its other lobby options take the host's values.
