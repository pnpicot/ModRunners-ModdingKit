# IOptions interface

The mod's options, which the player edits in the game. Each is declared in [`OnLoad`](../ModRunners.Api/IMod/OnLoad.md), in the order the options page shows them, and its value is saved between starts.

## Remarks

A value is saved under its option's id, so a label can change without losing it, and an id cannot.
