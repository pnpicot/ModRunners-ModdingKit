# IOptions.Lobby property

The options that set how the mod plays, which a modded lobby's host decides for every game. In a lobby another game hosts, they take the host's values, read-only on the options page, until the game leaves it. Options that only concern the player, such as keys and colors, belong to the mod's own options instead.

```csharp
public IOptions Lobby { get; }
```

## Remarks

While the host's value applies, setting [`Value`](../IOption-1/Value.md) keeps the value for when the game leaves the lobby, and [`Changed`](../IOption-1/Changed.md) is raised whenever the value in effect changes. The lobby options' own `Lobby` is themselves. The `Lobby` of a [`Group`](./Group.md) declares into that group.
