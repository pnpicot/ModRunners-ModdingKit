# IOptions.Group method

Options the options page shows together, under a tab of their own named *label*. Once the mod has options in two tabs, the options declared outside any group are under a tab named General. The tabs are in the order of their first option.

```csharp
public IOptions Group(string label)
```

| parameter | description |
| --- | --- |
| label | What the tab shows. |

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentException | *label* is empty. |

## Remarks

Each call with the same label declares into the same tab. Groups do not nest: a group's own `Group` is the mod's. The ids stay unique among all the mod's options, whatever their group.
