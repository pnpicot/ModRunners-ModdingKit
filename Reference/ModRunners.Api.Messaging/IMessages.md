# IMessages interface

Messages between this mod and its copies on the other games of a modded lobby. Each game runs the mod on its own, so a message tells the others what only this game knows or decides, such as a random choice. Runners, items, eliminations and rounds already reach every game without one.

## Remarks

A message is bytes the mod writes and reads itself. Messages from one game arrive reliably, in the order it sent them, but in no fixed order with the game's own messages: one sent after an elimination may arrive before it.
