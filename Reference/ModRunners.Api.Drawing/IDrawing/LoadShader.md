# IDrawing.LoadShader method

Loads a compiled shader from the mod's folder. The file is read at once, and turned into a shader the first time something is drawn with it.

```csharp
public IShader LoadShader(string path)
```

| parameter | description |
| --- | --- |
| path | Relative to the mod's folder, such as `Stars.fxb`. |

## Exceptions

| --- | --- |
