# IShader interface

A pixel shader from the mod's folder, which colors each pixel of the drawings made with it. It is an effect compiled with `fxc /T fx_2_0`, whose technique's passes have a pixel shader and no vertex shader.

## Remarks

The pixel shader gets the drawing's texture in sampler `s0`, white for a rectangle, its texture coordinates in `TEXCOORD0`, from (0, 0) at the drawing's top left corner to (1, 1) at its bottom right corner, and white in `COLOR0`. It returns a color whose red, green and blue are already multiplied by its alpha, as the game's drawings are.

A parameter keeps its value until it is set again. Each drawing uses the values the parameters have when it is made.
