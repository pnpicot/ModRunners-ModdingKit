# ICanvas interface

What a mod draws in the current frame. Each drawing goes to a [`Layer`](./Layer.md), in that layer's units, and only lasts this frame. A drawing on a layer the game does not show this frame is dropped. Within a layer, later drawings cover earlier ones.
