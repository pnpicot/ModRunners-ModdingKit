# IModTileType.Texture property

An image drawn over what its tiles draw in their main color, or null for the main color alone. It repeats across the level from the level's top left corner, one pixel per level unit, so it runs on from tile to tile. It never covers the tiles' marks or their transparent parts, so they keep their form, and its transparent parts show the main color.
