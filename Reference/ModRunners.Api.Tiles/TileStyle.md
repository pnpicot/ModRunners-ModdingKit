# TileStyle enumeration

How a tile is drawn among the level editor's tiles of its [`TileType`](./TileType.md). A tile's style changes nothing of what it does.

```csharp
public enum TileStyle
```

## Values

| name | value | description |
| --- | --- | --- |
| Plain | `0` | The plain drawing: the only one of blocks, grapple ceilings and wall-jump faces, and the slopes drawn as a plain triangle. |
| Stepped | `1` | A slope drawn as two steps of 8 by 8 units. It collides as the plain triangle, which the steps stick out of. |
| Checkered | `2` | Drawn with a checkerboard: the see-through block, and the slopes whose other half is a checkerboard, which players call see-through slopes. A checkered slope's checkerboard has no collision at all, and its triangle stops runners, hooks and items as a plain slope does. |
