# IXpScreen interface

The XP screen ("Points!!!") the game shows after a match: a panel with its title, its lines and the total, then the level bar, the new unlocks and, in a ranked match, the ranked progress. Each game shows its own player's, and every game moves on when the host's timer ends.

## Remarks

The game adds the XP and the unlocks when the screen opens, whatever a mod changes. A mod changes the panel's texts and lines in [`Ended`](./IMatch/Ended.md), before the lines pop in one by one. Nothing here is told to the other games.
