# OutCause enumeration

How a runner went out of a round. Every elimination is the camera's: the game keeps no cause, so it is read from the runner as it goes out.


## Values

| name | value | description |
| --- | --- | --- |
| LeftBehind | `0` | Left behind by the camera. |
| SuddenDeath | `1` | Left behind while sudden death shrank the camera. |
| Fell | `2` | Fell into the bottom of the level. |
| KnockedOut | `3` | Knocked out by spikes, a saw, a laser or an explosion, then lost by the camera. Hazards knock out only in a ranked match or with the Lethal Spikes modifier; otherwise they stun. On another game, a stunned runner's knock-out is not told, so it shows as LeftBehind or Fell there. |
