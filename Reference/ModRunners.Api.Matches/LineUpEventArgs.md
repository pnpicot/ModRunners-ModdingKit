## Remarks

The line's places stay the game's: for the first round, the level's start, where the runners stand 35 apart, the runners past four sharing places; for the next ones, the floor around the last round's winner. A handler only chooses who stands on each place. The game's own order is a shuffle the host makes for the first round, and for the next ones the last round's race order, its winner at the back and the runners out at the front.

Nothing is sent to the other games, so every game must give the same order, from data they all share, such as the slots' teams or scores.
