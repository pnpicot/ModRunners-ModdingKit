# IXpScreen.Duration property

How long the results last, as this game's screen counts them: about 7 seconds for a quick match, 4.25 more per unlock, 9.95 more in a ranked match. Every game moves on with the host's.

```csharp
public TimeSpan Duration { get; set; }
```

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | Set on a game that does not host the lobby ([`IsHost`](../../ModRunners.Api.Lobbies/ILobby/IsHost.md)). |
| ArgumentOutOfRangeException | The duration is below zero. |

## Remarks

Setting it, on the host, restarts the host's timer for that long from now, and every game moves on when it ends.
