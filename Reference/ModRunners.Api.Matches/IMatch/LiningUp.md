# IMatch.LiningUp event

Raised on the game's thread, on every game, as each round's runners line up at the start, so that a handler can choose their order ([`Order`](../LineUpEventArgs/Order.md)): for the first round, just after [`Started`](./Started.md), the runners at the level's start; for the next ones, as the last round's end places them, just before [`RoundEnded`](./RoundEnded.md), after the last round too. It is not raised while a replay plays.
