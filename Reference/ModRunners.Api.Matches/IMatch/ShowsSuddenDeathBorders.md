# IMatch.ShowsSuddenDeathBorders property

Whether the game draws the sudden death borders. True by default. When false, the level is drawn around [`CameraArea`](./CameraArea.md) instead, so a mod can draw borders of its own. Runners are still eliminated outside [`CameraArea`](./CameraArea.md).

```csharp
public bool ShowsSuddenDeathBorders { get; set; }
```

## Remarks

While it is false, the visible area of the level's layers ([`VisibleArea`](../../ModRunners.Api.Drawing/ICanvas/VisibleArea.md)) stays the whole screen during sudden death.
