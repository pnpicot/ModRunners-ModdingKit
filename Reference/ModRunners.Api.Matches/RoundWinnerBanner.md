# RoundWinnerBanner enumeration

What the game does with its banner when a round is won: the winner's portrait slides across the screen with its points, and the new point pops in, on the banner and in the HUD.

## Values

| name | value | description |
| --- | --- | --- |
| Shown | `0` | As the game shows it. |
| Hidden | `1` | Not drawn. The next round still waits the banner's 3 seconds, and the HUD's new point lights up when the banner's would have. |
| Skipped | `2` | Ended as soon as it starts, so the next round waits only for its fade, 0.2 seconds. The HUD's new point lights up at once. |
