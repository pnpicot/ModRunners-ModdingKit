# IRunningRules interface

How a runner speeds up and slows down on the ground. A runner holding a direction accelerates by the band its speed is in: [`SlowRunAcceleration`](./IRunningRules/SlowRunAcceleration.md) up to [`SlowRunSpeed`](./IRunningRules/SlowRunSpeed.md), [`RunAcceleration`](./IRunningRules/RunAcceleration.md) up to [`RunSpeed`](./IRunningRules/RunSpeed.md), and above it, it slows down by [`OverspeedDeceleration`](./IRunningRules/OverspeedDeceleration.md), so it settles at [`RunSpeed`](./IRunningRules/RunSpeed.md). Boosting moves where it settles up to [`HighSpeed`](./IRunningRules/HighSpeed.md) ([`IBoostRules`](./IBoostRules.md)).
