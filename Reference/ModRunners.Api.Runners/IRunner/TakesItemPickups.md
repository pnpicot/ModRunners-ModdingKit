# IRunner.TakesItemPickups property

Whether the runner takes the item pickups it touches. True by default. When false, it runs through them and they stay on the map.

```csharp
public bool TakesItemPickups { get; set; }
```

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | Set while the runner's slot is not played from this game ([`IsLocal`](../../ModRunners.Api.Lobbies/ISlot/IsLocal.md)), or once the runner no longer exists. |

## Remarks

It stays as set for the rest of the match, the next rounds included.
