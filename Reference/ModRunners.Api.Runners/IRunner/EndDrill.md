# IRunner.EndDrill method

Ends the runner's drilling now. It does nothing when the runner does not drill.

```csharp
public void EndDrill()
```

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | The runner's slot is not played from this game ([`IsLocal`](../../ModRunners.Api.Lobbies/ISlot/IsLocal.md)), or the runner no longer exists. |

## Remarks

In a modded lobby, every game ends it for its copy of the runner too. Elsewhere, the other games keep it until it runs out.
