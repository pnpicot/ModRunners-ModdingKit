# IRunner.Movement property

The values this runner moves by. Setting one gives the runner its own value, and the values it does not set keep following [`Movement`](../../ModRunners.Api/IGame/Movement.md). [`Reset`](../IMovementRules/Reset.md) has it follow [`Movement`](../../ModRunners.Api/IGame/Movement.md) again for every value.

```csharp
public IMovementRules Movement { get; }
```

## Remarks

It works on every runner, the other games' included, and stays as set for the rest of the match. A runner's values are not sent: in a modded lobby, a mod gives the same values to the runner's copy on every game, or the copies drift from where the runner's own game puts it.

Setting a value throws InvalidOperationException when the runner no longer exists.
