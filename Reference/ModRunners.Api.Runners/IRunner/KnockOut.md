# IRunner.KnockOut method

Knocks the runner out, as a lethal spike does: it lets go of its hooks, is thrown up, falls through the level, and is eliminated as soon as it leaves the view. It works in any match, not only where the game makes hazards lethal.

public void KnockOut()

| exception | condition |
| --- | --- |
| InvalidOperationException | The runner is already out or knocked out, no round is in play ([`IsRoundInPlay`](../../ModRunners.Api.Matches/IMatch/IsRoundInPlay.md)), the runner's slot is not played from this game ([`IsLocal`](../../ModRunners.Api.Lobbies/ISlot/IsLocal.md)), or the runner no longer exists. |

## Remarks

The other games are told, as for a spike, and knock their copy of the runner out too.
