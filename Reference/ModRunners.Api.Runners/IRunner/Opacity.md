# IRunner.Opacity property

How opaque the runner is drawn, from 0, invisible, to 1, the default. It covers the character, its effects, icons and hooks, and the player indicator, but not the rope, the trail or the popup texts.

```csharp
public float Opacity { get; set; }
```

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentOutOfRangeException | The value is not from 0 to 1. |
| InvalidOperationException | Set once the runner no longer exists. |

## Remarks

It stays as set for the rest of the match, the next rounds included. It only changes how this game draws the runner.
