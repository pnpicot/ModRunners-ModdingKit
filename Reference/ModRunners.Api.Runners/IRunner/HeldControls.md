# IRunner.HeldControls property

The controls the runner holds, as its game read them at its last frame: its player's keys or buttons, or a bot's choices. Under the srennuRdeepS modifier, which swaps the directions, Left and Right are the directions the runner moves in, not the keys pressed.

```csharp
public RunnerControls HeldControls { get; }
```

## Remarks

A runner reads its controls while a round plays. During the countdowns and between rounds, and while this game's chat, a popup or the player info is open, they stay as last read. While this game's pause menu is open in an online match, none is held. A bot holds UseItem for the frame it uses its item.

A runner another game plays has only Left, Right, Jump, Slide and Boost, as that game sends them about 30 times per second. Its other controls read as not held.
