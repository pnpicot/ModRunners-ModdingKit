# IRunner.JumpHoldTimeLeft property

How much longer its last jump can push it up while the jump button stays held: the jump's [`HoldTime`](../IJumpRules/HoldTime.md), 0.65 of it for a wall jump, less the time since the jump, and zero once it is over. It counts down whether the button is held or not, at the game's speed, so a jump let go early loses the rest of its push.

```csharp
public TimeSpan JumpHoldTimeLeft { get; }
```

## Remarks

The push applies at each frame that starts with time left, while the button stays down after the frame it was pressed on, and while the runner is in the air and is not swinging, tumbling, frozen, knocked out, pulled by a golden hook, or sliding after a jump. A landing, a lock of the grapple or a wall hang stop the push but leave the time left.
