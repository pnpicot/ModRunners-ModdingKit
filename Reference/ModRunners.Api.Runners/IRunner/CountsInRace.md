# IRunner.CountsInRace property

Whether the runner takes part in the race: the camera follows it, it is ranked by its progress, it can be eliminated, and it keeps the round going. True by default. A runner left out still runs and touches the others, but it ranks with the eliminated runners, never wins, is never eliminated, and the round ends as if it were out.

```csharp
public bool CountsInRace { get; set; }
```

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | Set while the runner's slot is not played from this game ([`IsLocal`](../../ModRunners.Api.Lobbies/ISlot/IsLocal.md)), or once the runner no longer exists. |

## Remarks

It stays as set for the rest of the match, the next rounds included. In a modded lobby, every game leaves its copy of the runner out of its race too. Elsewhere, only this game's camera and race leave it out: the other games keep counting it.
