# IRunner.Sounds property

How this runner's sounds sound. Setting a value gives the runner its own, and the values it does not set keep following [`Rules`](../../ModRunners.Api.Sounds/ISounds/Rules.md). [`Reset`](../../ModRunners.Api.Sounds/ISoundRules/Reset.md) has it follow [`Rules`](../../ModRunners.Api.Sounds/ISounds/Rules.md) again for every sound.

```csharp
public ISoundRules Sounds { get; }
```

## Remarks

It works on every runner, the other games' included, and stays as set for the rest of the match. A runner's values are not sent: they change how it sounds on this game only.

Setting a value throws InvalidOperationException when the runner no longer exists.
