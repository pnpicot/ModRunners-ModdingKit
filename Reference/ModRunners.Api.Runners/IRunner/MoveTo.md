# IRunner.MoveTo method

Moves the runner so that it stands at a point, as the game places the runners between rounds: it stops, and lets go of its hook and its golden hook. The point is not checked: a runner moved into the terrain is pushed out of it by its collisions.

```csharp
public void MoveTo(Point position)
```

| parameter | description |
| --- | --- |
| position | Where it stands, in level units, as [`Position`](./Position.md). |

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentOutOfRangeException | The point is not finite. |
| InvalidOperationException | The runner's slot is not played from this game ([`IsLocal`](../../ModRunners.Api.Lobbies/ISlot/IsLocal.md)), or the runner no longer exists. |

## Remarks

The move itself is not sent to the other games. Like every position of a runner, it reaches them about 30 times per second, and they pull their copy of the runner there over about a second, straight through the terrain. A runner pulled by another runner's golden hook keeps being pulled.
