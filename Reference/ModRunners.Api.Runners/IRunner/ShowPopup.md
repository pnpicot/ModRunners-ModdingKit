# IRunner.ShowPopup method

Shows a text above the runner the way the game shows its feats, such as "SUPER SPEED!": it grows in, then shrinks back for about 0.9 s. Texts shown together stack above the runner, the first shown nearest it, and close up as each goes. While the game shows its own popup, they stand above it.
