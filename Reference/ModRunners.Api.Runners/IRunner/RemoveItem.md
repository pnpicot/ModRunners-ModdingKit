# IRunner.RemoveItem method

Takes the runner's item away without using it, as using it would. A runner keeps its item when it is eliminated, and into the next rounds.

```csharp
public void RemoveItem()
```

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | The runner's slot is not played from this game ([`IsLocal`](../../ModRunners.Api.Lobbies/ISlot/IsLocal.md)), or the runner no longer exists. |

## Remarks

In a modded lobby, every game takes the item from its copy of the runner too. Elsewhere, the other games keep showing it.
