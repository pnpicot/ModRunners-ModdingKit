# IRunner.GiveModItem method

Gives the runner a mod's item in place of the one it holds, as an item pickup does.

```csharp
public void GiveModItem(IModItem item, int uses)
```

| parameter | description |
| --- | --- |
| item |  |
| uses | From 1 to the item's [`MaxUses`](../../ModRunners.Api.Items/IModItem/MaxUses.md). |

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentOutOfRangeException | *uses* is outside its range. |
| InvalidOperationException | The runner's slot is not played from this game ([`IsLocal`](../../ModRunners.Api.Lobbies/ISlot/IsLocal.md)), or the runner no longer exists. |

## Remarks

In a modded lobby, every game gives the item to its copy of the runner too. Elsewhere, the other games keep showing the runner's previous item, but they play the item's uses all the same.
