# IRunner.Freeze method

Freezes the runner, as the ice does, for a time: it slides to a stop and cannot act. Freezing a frozen runner starts its freeze again.

```csharp
public void Freeze(TimeSpan duration)
```

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentOutOfRangeException | The duration is not above zero. |
| InvalidOperationException | The runner's slot is not played from this game ([`IsLocal`](../../ModRunners.Api.Lobbies/ISlot/IsLocal.md)), or the runner no longer exists. |

## Remarks

Every game freezes its copy of the runner, and unfreezes it when the runner's own game does. Outside a modded lobby, the other games unfreeze it after 10 seconds at most.
