# IRunner.Revive method

Brings an eliminated runner back into the round, as the game does for every runner at the next round, but where it went out and without resetting it. It is shown again, collides with the level again, and its player controls it from the next frame. Move it with [`MoveTo`](./MoveTo.md), since it went out off camera or below the level.

## Remarks

In a modded lobby, every game brings its copy of the runner back too, and pulls it toward where its player's game puts it, as for any runner. Elsewhere, the other games are not told: they keep the runner out.
