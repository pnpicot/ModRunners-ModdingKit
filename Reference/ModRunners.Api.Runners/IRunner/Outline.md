# IRunner.Outline property

The line drawn around the runner's character, behind it, following the shape of its current animation frame: [`None`](../RunnerOutline/None.md), the default, draws none. It is drawn at the character's opacity, a ghost's included, and not while the character is hidden, as when the runner is out.

```csharp
public RunnerOutline Outline { get; set; }
```

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentOutOfRangeException | Its thickness is not from 0 to 10. |
| InvalidOperationException | Set once the runner no longer exists. |

## Remarks

It stays as set for the rest of the match, the next rounds included. It only changes how this game draws the runner.
