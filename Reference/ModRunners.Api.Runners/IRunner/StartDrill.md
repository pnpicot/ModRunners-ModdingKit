# IRunner.StartDrill method

Makes the runner drill for a time, as the InvinciDrill does, without using an item: its drill, sound, free boost and invincibility ([`IsDrilling`](./IsDrilling.md)). It blinks during the last half second.

```csharp
public void StartDrill(TimeSpan duration)
```

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentOutOfRangeException | The duration is not above zero. |
| InvalidOperationException | The runner's slot is not played from this game ([`IsLocal`](../../ModRunners.Api.Lobbies/ISlot/IsLocal.md)), or the runner no longer exists. |

## Remarks

In a modded lobby, every game makes its copy of the runner drill too. Elsewhere, the other games are not told, so their copy does not drill there.
