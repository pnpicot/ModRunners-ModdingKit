# IRunner.GiveItem method

Gives the runner an item in place of the one it holds, as an item pickup does.

```csharp
public void GiveItem(Item item, int uses = 1)
```

| parameter | description |
| --- | --- |
| item |  |
| uses | 1 to 3 for the box and the rockets, which are the triple items with 3, and 1 for every other item. |

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentOutOfRangeException | *uses* is outside its range. |
| InvalidOperationException | *item* is the detonator while the runner's bomb is not placed, the runner's slot is not played from this game ([`IsLocal`](../../ModRunners.Api.Lobbies/ISlot/IsLocal.md)), or the runner no longer exists. |

## Remarks

In a modded lobby, every game gives the item to its copy of the runner too. Elsewhere, the other games keep showing the runner's previous item, but they play its uses all the same.
