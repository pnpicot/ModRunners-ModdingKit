# IRunner.Items property

The values this runner's items play by: the items it uses, and their effects on the runners they reach. Setting one gives the runner its own value, and the values it does not set keep following [`Rules`](../../ModRunners.Api.Items/IItems/Rules.md). [`Reset`](../../ModRunners.Api.Items/IItemRules/Reset.md) has it follow [`Rules`](../../ModRunners.Api.Items/IItems/Rules.md) again for every value.

```csharp
public IItemRules Items { get; }
```

## Remarks

It works on every runner, the other games' included, and stays as set for the rest of the match. A value applies from the next time the game reads it: when the item is used for most, when they land for stuns and freezes, and at every frame for the fireball's growth and gravity, the rocket's homing growth, the ice beam's thickness and the golden hook's pull.

A runner's values are not sent: in a modded lobby, a mod gives the same values to the runner on every game, or its items play differently there.

Setting a value throws InvalidOperationException when the runner no longer exists.
