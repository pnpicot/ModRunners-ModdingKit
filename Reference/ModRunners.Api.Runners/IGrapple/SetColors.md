# IGrapple.SetColors method

Gives the runner of a slot its own colors, which it is drawn with instead of [`Colors`](./Colors.md).

```csharp
public void SetColors(ISlot slot, GrappleColors colors)
```

## Remarks

The colors stay with the slot's place in [`Slots`](../../ModRunners.Api.Lobbies/ILobby/Slots.md), whoever plays in it, until they are cleared. To follow a player, set them again when a level is built ([`LevelChanged`](../../ModRunners.Api/IGame/LevelChanged.md)).
