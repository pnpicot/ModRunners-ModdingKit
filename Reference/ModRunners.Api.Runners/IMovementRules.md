## Remarks

[`Movement`](../ModRunners.Api/IGame/Movement.md) is the rule for every runner. A runner can have its own values ([`Movement`](./IRunner/Movement.md)), and follows the rule for the others.

The values are the game's base values. Under Super SpeedRunners, and for bots, the game multiplies most of them by its own factor, which it keeps applying to a changed value.

Every game simulates every runner with its own values, and no value is sent to the other games: a runner whose values differ on some games of a match drifts there, and is pulled back toward the positions its own game sends.
