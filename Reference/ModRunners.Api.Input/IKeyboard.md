# IKeyboard interface

The keyboard, as gameplay reads it. Keys reach mods while the game's window is active, and while neither the chat, a popup, the player info nor the pause menu takes them.

## Remarks

The game reads its own keys too. With the default bindings, the arrows, Z, X, C and Space play and move through the menus, T taunts, Tab shows the player info, Enter opens the chat and Escape the pause menu. A mod's key on one of them does both.
