# IGame.RunnerActed event

Raised on the game's thread when a runner acts as it moves, such as a jump, a landing or a stumble. Every game raises it for every runner it simulates, and the runner's own game decides ([`IsDecidedHere`](../../ModRunners.Api.Runners/RunnerActedEventArgs/IsDecidedHere.md)).

```csharp
public event EventHandler<RunnerActedEventArgs>? RunnerActed;
```

## Remarks

The start and end of a wall hang, a slide, a boost, a tumble and a super boost are seen at the runner's next frame of movement.
