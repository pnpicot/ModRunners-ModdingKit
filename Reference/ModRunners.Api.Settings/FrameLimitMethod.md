# FrameLimitMethod enumeration

How the game waits for the next frame, numbered like the launch option `+framelimitmethod`.

```csharp
public enum FrameLimitMethod
```

## Values

| name | value | description |
| --- | --- | --- |
| Yield | `0` | Lets another thread run if one is ready, otherwise checks again at once. The game's default. |
| SleepZero | `1` | Gives the rest of its time slice to a thread of the same priority if one is ready, otherwise checks again at once. |
| Sleep | `2` | Sleeps at least 1 millisecond between checks, so the timing depends on Windows' timer. |
| BusyWait | `3` | Checks the clock without ever pausing, which keeps one processor core busy. |
